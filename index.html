CARIOCA

v0.1.0-dev
Fase 1 — fundação

Jogo 3D de mundo aberto inspirado no Rio de Janeiro e em Niterói. Feito com Godot 4.4 e GDScript, alvo iPhone 12, custo zero.

Esta página é um cartão de apresentação do projeto. O jogo é um aplicativo Godot: o navegador só abre o build exportado pelo próprio motor, que é gerado automaticamente pelo GitHub Actions e publicado no GitHub Pages.

Abrir o build web

Se ainda não abrir, o build web ainda não foi gerado. Veja como abaixo.

Como jogar agora

  • No iPhone: aba Actions do GitHub → workflow build web verde → abra o endereço do GitHub Pages no Safari.
  • No computador: instale o Godot 4.4.x, abra a pasta do projeto e aperte F5.
  • Só validar o código: godot --headless --path . -s tests/runner.gd

Passo a passo completo em docs/TESTAR.md.

Controles

  • Metade esquerda da tela — joystick de andar
  • Metade direita — arraste para girar a câmera
  • Botões PULAR e CORRER
  • No teclado: WASD, Shift, Espaço

O que já funciona (escrito)

  • Cidade procedural por setores de 512 m, com streaming
  • Orla, avenida, ruas, quadras, prédios, praças e palmeiras
  • Personagem em terceira pessoa com câmera orbital
  • Ciclo dia/noite, clima e céu procedural
  • Salvamento versionado com checksum

Nada disso foi executado ainda: o projeto nunca rodou no Godot. O estado real, incluindo os bugs conhecidos, está em docs/STATUS.md.
